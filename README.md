# Road Encounters

A Kingdom Come: Deliverance II mod that makes road encounters bigger, but not more frequent.

The quest files in `src/` are generated from the vanilla ones by `generate_src.py`, with the size factors at the top of the script. The mod is packaged with [kcd2-mod-packager](https://github.com/ddbb07/kcd2-mod-packager).
